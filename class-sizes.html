Counting the Functions in Each Class

An affine equivalence class groups Boolean functions that share the same cryptographic properties. But how big is each class, that is, how many of the $2^{2^n}$ functions does it contain? The PhD research behind this site answered this exactly for every class with $n \le 6$, using what the thesis calls the self-mapping constant.

Self mappings

An affine transform maps $f$ to $g(x) = f(Dx \oplus a) \oplus b \cdot x \oplus c$, where $D$ is an invertible $n \times n$ binary matrix, $a, b \in \mathbb{Z}_2^n$ and $c \in \mathbb{Z}_2$. A transform that maps $f$ to itself is a self mapping of $f$. The identity is always one, so every function has at least one.

The thesis proves three facts about self mappings (Chapter 4):

  1. The self mappings of $f$ form a subgroup of the affine group, so their number, $\theta$, divides the order of the group.
  2. If $f$ and $g$ are equivalent, the number of distinct transforms taking $f$ to $g$ is exactly $\theta$, the number of self mappings of $f$.
  3. Equivalent functions have the same number of self mappings, so $\theta$ is a property of the whole class: the self-mapping constant.

The class-size formula

Counting the choices for $D$ (row $k$ can be any vector outside the span of the previous rows, giving $2^n - 2^k$ choices), $a$, $b$ and $c$, the total number of affine transforms is

$$\mathcal{T} = 2^{2n+1} \prod_{i=0}^{n-1} \left(2^n - 2^i\right).$$

Since every function in a class $\mathcal{C}$ is reached from $f$ by exactly $\theta$ of these transforms, the number of functions in the class is simply

$$\#\mathcal{C} = \frac{\mathcal{T}}{\theta}.$$

(This is an instance of the orbit–stabiliser theorem; the self mappings are the stabiliser of $f$ in the affine group.) The bounds follow immediately: $\theta \ge 1$, and the largest $\theta$ belongs to the smallest class, the affine functions, with $2^{n+1}$ members.

$n = 6$: the self-mapping distribution

For the 150,357 classes of $n = 6$ there are 122 distinct values of $\theta$. Most classes have no symmetry at all: 91,184 classes have $\theta = 1$ (only the identity), so each contains the full $\mathcal{T} = 165{,}140{,}150{,}353{,}920$ functions. A further 32,454 have $\theta = 2$ and 12,522 have $\theta = 4$. At the other extreme, the affine class has $\theta = 1{,}290{,}157{,}424{,}640$.

How many functions have each nonlinearity? ($n = 6$)

Summing the class sizes over the classes at each nonlinearity gives the exact number of 6-variable functions with that nonlinearity. For nonlinearity below 16 these follow from a known closed formula, $\binom{64}{N} \cdot 2^{7}$; for 16 and above, the thesis obtained them by summing class sizes. The total is exactly $2^{64}$, and the 5,425,430,528 functions of nonlinearity 28 are precisely the bent functions, summed over the four bent classes.
