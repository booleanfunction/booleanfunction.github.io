Affine Equivalence Classes

Definitions

An affine transform maps a Boolean function $f$ to a function $g$ such that

$$g(x) = f(Dx^{T} + a^{T}) + b \cdot x^{T} + c,$$

where $D$ is an $n \times n$ invertible matrix over $\mathrm{GF}(2)$, $a$ and $b$ are $n$-bit vectors, and $c$ is a binary constant. Two functions related by an affine transform are affine equivalent, and the set of all functions equivalent to a given $f$ forms its affine equivalence class.

Affine transforms preserve the most important cryptographic properties — nonlinearity, algebraic degree, the absolute Walsh–Hadamard spectrum and the absolute autocorrelation spectrum are all invariant across a class. Classifying functions into equivalence classes therefore reduces the study of $2^{2^{n}}$ individual functions to a far smaller set of representatives.

The tables below give, for each class: an example truth table (hex), the algebraic order (ord), the nonlinearity (nl), and the distributions of absolute Walsh–Hadamard (WHT) and absolute autocorrelation (AC) values, written as $\{(\text{value}, \text{multiplicity}), \ldots\}$.

In coding-theory terms

Boolean functions have a natural home in coding theory. The truth tables of all functions of degree at most $r$ form the binary Reed–Muller code $\mathrm{RM}(r,n)$, and the affine functions are exactly $\mathrm{RM}(1,n)$. Collecting a function together with all of its affine offsets gives a coset of $\mathrm{RM}(1,n)$, and the affine equivalence classes are the orbits of these cosets under invertible affine changes of variable — the maps $x \mapsto \mathcal{D}x \oplus a$ with $\mathcal{D} \in \mathrm{GL}(n, \mathrm{GF}(2))$. This is the viewpoint from which J. A. Maiorana first enumerated the 150,357 classes of $\mathcal{B}_6$ in 1991.

The same language describes the cryptographic measures directly: the nonlinearity of $f$ is its Hamming distance to $\mathrm{RM}(1,n)$, and the bent functions — the maximum-nonlinearity classes, which exist only for even $n$ — attain the covering radius of $\mathrm{RM}(1,n)$. More generally, the distance from $f$ to $\mathrm{RM}(r,n)$ is its $r$-th order nonlinearity.

Data files

The complete classification gives one representative function for every class. It is split into one file per combination of nonlinearity, algebraic order and maximum absolute autocorrelation $(\text{nl}, \text{ord}, \text{acmax})$. These data files accompanied the original site and have been used by other researchers, for example in NIST's study of the multiplicative complexity of 6-variable Boolean functions.

  • All classes (n6-classes.zip, 670 KB): 182 files, 150,357 class representatives.
  • Classes containing balanced functions (n6-balanced-classes.zip, 335 KB): 94 files (n6_bal_…), 74,542 classes.

Format. Plain text, one class per line:

class=150341; tt=0x110707FF,0xE0422107;

class is the class number and tt is the 64-bit truth table of a representative, written as two 32-bit words. In the balanced files the classes are numbered separately (1–74,542). Each class contains at least one balanced function, but the representative listed is the class's usual representative and is not necessarily balanced itself.

History of this data

  • 1991. Maiorana classified the cosets of the Reed–Muller code $R(1,6)$, establishing that there are 150,357 affine equivalence classes for $n = 6$. That work, in coding-theory terms, gives weight distributions and stabiliser orders rather than representative functions with their cryptographic properties.
  • 2003. The PhD research behind this site re-enumerated all 150,357 classes using the Theorem of Connectivity and produced, for every class, a truth-table representative together with its nonlinearity, algebraic order and autocorrelation, identified the 74,542 classes containing balanced functions, and counted the functions in each class via a self-mapping constant (tabulated in the thesis appendices). The data files were published on the original Boolean Planet website in 2003 and described in the thesis (December 2003).
  • 2018. Çalık, Sönmez Türan and Peralta computed the multiplicative complexity of every $n = 6$ class, using these representative functions (ePrint 2018/002).
  • 2026. The original files are re-released here unchanged, after re-validation: the class totals, and the properties of a random sample of representatives against their file names.
